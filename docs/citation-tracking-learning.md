# 引用追踪 Agent：从种子论文发现相关研究

## 使用方法

1. 在收藏夹勾选 1 至 5 篇论文，点击“追踪所选论文引用”。
2. 保持默认主题或填写具体方向，例如“SEED-IV 与 SEED-VII 多模态情绪识别中的 EEG 和眼动融合”。选择双向、参考文献或后续研究，设置结果数量后提交。
3. 在任务详情查看候选及发现路径。参考文献表示种子引用候选；后续研究表示候选引用种子。关系中箭头始终是引用者 → 被引用者。
4. 将需要的候选加入收藏，再通过正文准备、PDF 上传和学习报告流程深入阅读。

引用追踪使用个人设置中的默认模型，执行 live 模式；无需先上传种子的 PDF。它查询来源记录中的引用关系，不从模型记忆中生成论文列表。未找到引用记录或身份无法匹配，不代表论文没有相关研究。

## 与普通搜索的区别

普通搜索依靠关键词匹配元数据，智能搜索增加问题分析、查询规划和补搜。引用追踪从已知论文出发查找有明确引用关系的研究，可以发现措辞不同的相关论文。但它依赖来源的引用覆盖，不能保证查全，也不能替代全文阅读。

第一版新增独立的 citation_trace 任务，未自动改变现有智能搜索的执行成本。用户可以先搜索、收藏，再选择论文发起追踪。

## Java 与 Python 如何协作

Java 从登录账号的收藏夹读取种子快照，验证论文归属、数量、方向和个人模型配置，保存幂等任务。结果数量与种子数量独立。引用追踪与智能搜索共享同账号最多两个进行中任务的配额，避免连续点击产生大量昂贵任务。

Python 的 OpenAlex 适配器使用固定 HTTPS API，不访问输入或响应指定的任意接口。优先用 OpenAlex W 编号查询；DOI 和规范 arXiv DOI 必须精确匹配，不能根据相似标题猜测身份。部分论文没有对应的规范 arXiv DOI 记录时会提示无法映射。

参考文献来自种子 referenced_works；后续引用来自 cites 查询，并检查候选记录中确实存在对种子的引用。先由程序生成引用边，再把标题和摘要交给模型判断与研究问题的相关性。模型不能增加论文、修改编号或生成引用路径。

筛选结果中的证据须逐字出自候选标题或摘要。证据不足、指定实体缺失或多模态依据不足时，匹配结果降为待核实。这里核实的是元数据相关性；引用关系本身不意味着赞同或支持结论。

## 预算、版本和失败处理

- 最多 5 个种子，只追踪一层；不会因为引用循环继续递归。
- 每个种子每个方向最多 20 条，合计保留最多 60 个去重候选，返回最多 20 篇。
- 来源请求最多 20 次、模型阶段最多两次、任务处理限时 120 秒；单次来源请求 8 秒，响应最多 4 MiB。
- 来源限流、超时或截断会明确提示；部分来源失败仍保留成功方向。全部失败时记录任务失败，不伪装成正常的零结果。
- 根据论文身份去重，同一 OpenAlex 论文保留多条发现路径；同 DOI 对应不同 W 编号时跳过无法保持原编号的别名路径，避免改写引用边。
- 原输入重试保留种子和方向快照，模型凭证按现有机制临时传递，不写入任务输入和公开结果。

原有研究任务、搜索任务与全文学习报告保持兼容；旧任务的空方向字段不参与持久化输入，避免改变幂等校验。

## 从哪里学习实现

| 文件 | 重点 |
| --- | --- |
| paper_agent/core/citation_agent.py | 类型契约、方向、引用路径和报告约束 |
| paper_agent/tools/citation_graph.py | 固定来源、身份匹配、双向邻居查询和预算 |
| paper_agent/services/citation_tracking.py | 去重、发现路径、相关性审查与部分失败 |
| paper_agent/interfaces/worker.py | 新任务接入、输入校验、快照和安全错误 |
| java-backend/src/main/java/cn/paperflow/service/impl/ResearchTaskServiceImpl.java | 账号归属、幂等任务、模型选择与重试 |
| java-backend/src/main/java/cn/paperflow/client/CitationReportValidator.java | 跨服务结果的独立校验 |
| frontend-vue/src/components/CitationReportView.vue | 方向解释、依据展示和保存收藏 |

适配器和筛选模型可以分别注入替身，从而用固定引用图测试方向、循环、去重、限额和来源故障；真实模型效果和来源可用性需要额外评测。测试通过不表示已经验证任意主题的召回率。

代码在本地实现，需要构建并启动新版 Java、Python 与 Vue 才能使用。本轮没有自动发布 GitHub或重启用户正在使用的服务。

参考：[OpenAlex 引用查询](https://help.openalex.org/how-to/api-recipes/)、[PaSa 的发现与筛选分工](https://github.com/bytedance/pasa#architecture)。
