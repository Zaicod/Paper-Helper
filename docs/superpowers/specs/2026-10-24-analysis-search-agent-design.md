# 分析式论文搜索 Agent：设计草案

状态：用户于 2026-10-24 确认，已完成本轮实现与验证。本轮先实现搜索页面的“智能搜索”，保留普通搜索；后续再接入自动研究任务的论文获取阶段。

## 问题与真实验收案例

用户输入：`多模态情绪识别 seediv seedvii`。

现有搜索原样发送中文，不分析任务、模态和数据集；结构化关键词通常使用 AND，自动来源是找到结果即返回的顺序回退，不合并不同来源，也不检查结果是否对题。研究流程也直接把主题交给搜索适配器。

这次现场核对的参考事实：上海交大 BCMI 的 SEED 项目正式命名包括 SEED-IV 和 SEED-VII，两者均提供 EEG 与眼动数据。SEED-IV 官方参考为 EmotionMeter，DOI 10.1109/TCYB.2018.2797176；SEED-VII 官方参考 DOI 为 10.1109/TAFFC.2024.3485057。这些用作离线验收样例的来源依据，不把特定领域别名写死为整个搜索 Agent 的能力。

- https://bcmi.sjtu.edu.cn/home/seed/
- https://bcmi.sjtu.edu.cn/home/seed/seed-iv.html
- https://bcmi.sjtu.edu.cn/home/seed/seed-vii.html

本例默认将两个数据集理解为“任一相关”，分别检索后合并；结果单独标出哪个数据集有依据。不能要求每篇论文同时包含两个数据集，也不能把仅使用普通 SEED 的论文当成指定数据集匹配。

## 三种方案与本轮选择

1. 只做查询翻译与改写：成本较低，但不能判断召回是否偏题，也无法根据结果补搜。
2. 搜索计划 → 多来源检索 → 相关性审查 → 一轮补搜：推荐。在有限成本内形成可解释、可验证的搜索流程。
3. 全文下载、引文网络追踪与持续自主搜索：有助于系统综述，但涉及更长执行时间和更多来源，本轮不展开。

## 用户可见行为

- 搜索页新增“智能搜索”，接收自然语言问题；原关键词搜索、分页与收藏继续独立工作。
- 显示结构化的搜索理解：任务、模态、指定实体及别名、约束、各实体之间的 AND/OR 关系。本例识别为 emotion recognition、multimodal，以及 SEED-IV / SEED-VII 两个数据集，EEG / eye movement 作为结合官方背景得到的搜索扩展，明确标示为扩展假设。
- 展示实际执行的查询、文献来源、搜索轮次、失败提示、去重后的候选及入选理由。展示简要搜索决策，不展示模型内部推理过程。
- 结果按明确匹配、待核实、补充背景区分；只有标题或摘要包含证据时才标注“提及该数据集”。不能仅因模型推测或数据集名称相近，就断言论文使用该数据集。
- 本例优先召回 EEG 与眼动的多模态研究。只使用 EEG 的论文标为单模态相关；语音、文本或人脸的泛多模态论文若没有指定数据集证据，不进入明确匹配。
- 每篇仍提供真实论文来源、摘要、链接和收藏操作。没有足够匹配时明确说明缺口，不能为凑数量混入无关结果。

## 执行架构

Vue → Java 创建智能搜索任务 → 现有同步器 → Python 搜索 Agent → 真实文献适配器 → 审查与补搜 → Java 保存结果 → Vue 展示。

- Python 独立 SearchAgent 负责计划与结果审查，使用现有模型适配方式；代码控制工具执行、轮数与预算。检索依赖可注入，便于离线测试。
- 计划使用 Pydantic 结构化输出，包括概念、实体别名、必须满足的条件及有限查询列表。模型不直接拼接 URL 或执行任意查询语法，仍由现有适配器编译参数。
- Java 复用登录身份、个人默认模型、加密凭证派发、任务幂等及本轮已完成的调度机制。扩展任务类型及搜索结果契约，避免让长搜索挤进当前 25 秒的同步搜索请求。
- 搜索结果与研究报告区分类型；页面不会把智能搜索结果误显示成已完成全文分析的研究报告。搜索相关进展继续归入 search 阶段，具体消息区分理解、检索、审查、补搜。
- 用户当前默认模型未配置时，清晰引导个人设置；普通搜索仍可使用，不把规则替身伪装成模型搜索。

## 检索、去重与证据约束

- 显式调用现有 arXiv、OpenAlex、Crossref 适配器，分配查询预算；某来源返回少量结果后，不因此取消所有其他来源检索。
- 严格条件与检索扩展分开。指定数据集等硬约束不能因结果不足而静默删除；可放宽辅助方法词，所有放宽需要记录。
- 按可获得的规范化 DOI、arXiv 标识或规范化页面链接去重；跨来源仅在标题及其他元数据足以确认时合并，不强行合并同名论文。保留每次命中的来源与查询。
- 模型只能引用候选列表中的内部 ID；论文标题、作者、年份、链接仍从适配器验证后的元数据读取。模型新编出的论文或未提供的链接不进入结果。
- 推荐理由必须指向候选标题或摘要的原文片段，代码验证片段确实来自该候选；缺摘要时标记证据不足。元数据中没看到数据集名称不代表全文一定没用该数据集，保留待核实状态。
- 本轮不新增全文下载。不能把“提及数据集”直接升级为“实验使用数据集”或“效果最好”；这些需要后续正文核对。

## 预算与失败处理

- 最多 2 轮检索、累计最多 6 次来源请求、3 次模型调用；候选最多保留 60 篇，展示最多 20 篇。提前找到足够有依据的结果时停止。
- Agent 执行总期限 120 秒，覆盖模型调用、来源等待及补搜；现有来源超时和 arXiv 请求间隔继续生效。实际等待可能含排队与 Java 后续状态同步，页面不承诺 120 秒内一定出结果。
- 每用户最多 2 个活动智能搜索任务，创建任务沿用现有生成请求限流；幂等重放不重复计数。智能搜索包含模型调用，不能作为公开搜索缓存结果跨账号共享。
- 来源部分失败时保存已有可信结果并提示未覆盖范围；全部来源失败时显示来源故障，不能宣称没有相关论文。
- 模型规划或审查失败时任务提供明确错误及重新执行入口，不返回未经标注的“智能筛选”结果。重试仍通过新记录保留旧任务。

## 测试与验收

1. 固定模型与文献源替身：本例生成分开的 SEED-IV / SEED-VII 查询；保留指定实体，中文转为相关学术词，两个数据集默认 OR。
2. 候选夹杂仅 EEG、仅普通 SEED、语音人脸、仅引用数据集和无摘要论文：审查必须正确区分有依据、待核实和背景，不能伪造实验使用结论。
3. 模型返回不存在的候选 ID、错误证据片段或编造链接：代码拒绝这些内容，不污染原论文元数据。
4. 覆盖跨来源去重、部分失败、全失败、零结果、一轮补搜、请求/轮数/总期限上限。
5. Java 验证账号隔离、任务幂等、个人凭证、并发配额与重试；Vue 验证进度、结果说明和收藏，同时回归普通搜索。
6. 可联网时另外记录真实检索；固定样例只能证明流程正确，不能宣称外部 API 实时可用或检索完整。未经用户要求不使用真实个人模型密钥进行验收。
