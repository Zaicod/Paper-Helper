# ChromaDB 论文向量持久化

状态：用户已确认整体设计，进入实施；使用本地多语言向量模型。

## 目标与推荐方案

Python 接入本地持久化 ChromaDB，保存论文文本片段、向量和可追溯元数据；普通研究与学习报告实际从 Chroma 查询证据，不只把向量写进去。Java 继续使用 Controller → Service → ServiceImpl → MyBatis 管理用户、收藏夹、笔记和任务。

推荐 PersistentClient，数据默认放入 outputs/chroma，随 Python 启动，无需单独启动数据库服务。另一方案是独立 Chroma Server，适合以后多进程或分布式部署，但当前单进程学习项目暂不引入额外服务。

用户选择本地多语言模型，无需 Embedding API Key，首次需下载模型。建议使用 multilingual-e5-small 类轻量多语言语义模型，最终依赖与模型在当前 Windows/Python 环境中做兼容验证。HashingEmbedder 只保留给明确的离线演示和快速测试，不能冒充实际语义向量模型。现有大模型生成报告仍需可用的大模型配置，此次免 Key 仅指向量生成。

## 数据与检索

- 每条记录保存 chunk_id、正文 text、embedding，以及服务端账号命名空间、论文来源和 ID、内容版本、页码、来源 URL、来源模式。
- 保存模型身份、向量维度与切分版本；不同向量模型/维度分开建集合，不把新模型向量混入旧集合。
- ID 按命名空间、论文身份、版本和片段确定性生成，使用 upsert，重复建索引不增加同版本重复片段。
- 页面仍只通过 Java 提交本人收藏论文。账号命名空间由 Java 在内部请求中生成，不接受浏览器指定任意命名空间。旧任务无账号信息时使用任务独立命名空间。
- 每次检索同时限定命名空间、当前所选论文及其版本，不能跨用户或召回未选中的论文；单篇分析再限定 paper_id。
- 返回证据保留 chunk_id、paper_id、页码与来源，供 Agent 引用校验和报告展示。

## 建立索引与复用

收藏动作仍只保存业务资料。第一次研究或生成学习报告时获取正文、解析、切分、向量化并写入 Chroma；后续任务复用已完成的索引。

缓存身份包括论文资料、PDF 链接、模型、切分版本和实际正文版本。论文资料/PDF 链接变化时使用新版本；同一 URL 下正文变化通过显式重建刷新，不宣称后台能自动探测所有远端更新。提供后端/命令行重建入口，首期不额外新增复杂索引管理页面。

索引只有完整写入成功才标为可复用，失败的部分数据不能被查询为完整论文。旧报告保留原有证据快照，不因重建覆盖历史内容。

## 两条 Agent 流程

普通研究：沿用 PaperRAG 对摘要/PDF 的现有选择，新增可替换向量存储接口和 Chroma 实现，查询仍经过上下文预算控制。演示使用原有内存/本地哈希实现，真实 Chroma 故障不能静默退回演示。

学习报告：替换只按关键词打分挑片段的做法。严格获取 PDF 正文或复用既有 PDF 索引，使用背景、方法、实验结果等查询召回候选，再构造受预算限制的上下文交给 Agent。无 PDF 仍失败并提示补充，不自动用摘要冒充正文。保留选中论文逐篇覆盖与引用校验。

## 失败与兼容

- 模型首次下载失败时提示模型准备问题，不让 Python 服务启动时就因下载阻塞；真正需要向量化时按需加载。
- 同一进程共用受控的模型加载，批量向量化不阻塞 HTTP 事件循环；并发任务不能重复下载或串用索引范围。
- 索引目录不可写、维度不匹配、空文本、模型故障等显示可理解错误，不声称已成功持久化。
- 不开放未鉴权的 Chroma 网络接口。此次不实现自动将业务删除同步为物理向量删除；取消收藏后新的任务不能再选择这些论文，旧向量仅在内部命名空间内保留供历史与后续维护。
- 原有 JSON 索引不自动覆盖或删除；新建 Chroma 数据独立存放。原 CLI、演示及测试通过可注入存储/Embedder 保持兼容。

## 验收

1. 使用真实 Chroma 临时目录写入，关闭并重新打开，验证片段与向量仍存在，不能只用内存假库证明持久化。
2. 真实本地模型处理中文和英文片段，验证相同模型的文档/查询前缀与向量维度，检查语义检索结果。
3. 验证重复写入、版本隔离、模型切换隔离、账号隔离、所选论文范围及页码引用。
4. 学习报告确实使用 Chroma 召回结果，缓存复用不重新生成已有向量；建索引中断不留下可用的半成品。
5. 运行现有 Python、Java 和 Vue 相关回归；涉及界面/API 契约时补充浏览器验收。真实下载或运行时不兼容须明确报告，不能用 HashingEmbedder 或模拟 Chroma 冒充完成。
