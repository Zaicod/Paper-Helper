# 按账号保存模型设置

状态：用户于 2026-10-19 明确要求“新增模型设置页面，开始”；实现及回归验证已完成，使用说明见 docs/model-settings-learning.md。

## 需求与推荐方案

现有学习报告和研究任务只使用 Python 进程环境中的 DASHSCOPE_API_KEY / OPENAI_API_KEY。新增登录后的“模型设置”页面，用户可在项目界面配置自己的密钥和默认模型，学习报告与普通真实研究任务均能使用。

推荐 Java 按账号加密持久化，Python 按任务使用配置。另一种方式是密钥只保存在当前浏览器或仅在当前运行期间使用，操作较简单，但换浏览器或重启后丢失，也不适合现有后台排队任务，因此不作为默认方案。

## 页面与操作

- 侧栏新增“模型设置”。首期支持现有通义千问 Qwen / OpenAI 两种提供商，不新增第三方任意地址配置。
- 每个提供商分别保存密钥和默认模型，可选择默认提供商；页面提供预设模型和手工输入模型名称，实际可用性以账号权限和测试结果为准。
- 密钥输入框使用密码样式。读取设置只返回“已配置”、末尾脱敏提示和默认模型，不回传完整密钥。
- 点击保存更新设置；编辑模型时密钥留空表示保留原密钥，“删除密钥”是单独操作，避免误清空。
- 提供“测试连接”，使用已保存配置做一次有严格超时与输出上限的实际模型调用。页面说明该测试会调用模型并可能消耗少量额度。失败只显示可理解且脱敏的原因。
- 新建学习报告/真实研究默认载入个人提供商和模型，也可在提交时覆盖模型名称；没有个人配置时保留已有服务端环境变量兼容方式。缺少配置时提示去设置页，不再只要求用户配置环境变量。

## Java 业务分层与存储

- Controller 接收设置、删除、连接测试请求；写操作沿用登录与 CSRF 校验。
- ModelSettingsService 接口与 ServiceImpl 处理归属、校验、脱敏与默认配置；MyBatis Mapper 读写模型设置表，仍为单模块三层架构。
- Flyway 新增迁移，不删除已有账号、资料或任务。
- 密钥使用标准 AES-GCM 加密后存入数据库；不写入日志、异常文本、前端 localStorage、普通任务 JSON 或响应 VO。
- 本地学习环境第一次保存时自动创建服务端加密主密钥文件，放在已忽略的本地数据目录；避免用户额外手工设置另一个环境变量。文件权限尽量限定运行账号。主密钥在重启后复用，缺失或解密失败时明确提示重新配置，不静默覆盖。
- 备份设置时需要同时保留数据库与主密钥文件；页面不提供完整密钥导出。

## Java 到 Python 的任务执行

- 任务持久化只保存提供商、模型等非秘密快照，密钥由 Java 在真正派发任务时读取并经已有服务身份保护的内部请求传递。
- Python 将凭证作为任务局部依赖使用，不修改 os.environ，也不设置全局 SDK 默认密钥，避免不同用户并发时串用。
- 新的运行时凭证从任务哈希及 SQLite 持久 payload 中排除，仅保留到当前执行结束；完成、失败和关闭时清理。
- 重复派发同一任务不会覆盖已经在运行的凭证。执行端重启仍沿用当前“未完成任务标记中断”的行为，不承诺静默续跑。
- 待派发任务读取当时仍可用的个人密钥；用户删除密钥后，依赖该配置而尚未执行的任务会明确失败。已经派发的任务继续使用派发时的凭证。
- 原有环境变量仅在未选择个人配置的兼容路径中使用。已选择个人配置但密钥不可用时不能偷偷改用别人的或服务端的 Key。
- 旧任务和离线演示保持兼容，现有学习报告导出不需要额外模型调用。

## 边界与验收

- 两个账号的读取、修改、删除、默认选择和任务调用相互隔离。
- 验证数据库及 Python 持久任务中不出现明文密钥，GET 设置只返回脱敏信息；模型错误、鉴权失败和远端异常均不泄露凭证。
- 验证保存后刷新/重启仍可用，留空保留密钥，单独删除正确生效；加密文件丢失不导致默默更换密钥。
- 使用受控模型边界测试按账号派发、并发不同 Key、同任务重试和旧任务兼容；真实模型测试需要用户本地已经保存的有效配置，不要求在聊天中发送密钥。
- 浏览器覆盖配置、默认模型、测试连接、创建学习报告和刷新恢复；保留现有论文检索、收藏夹及 DOCX 下载回归。

## 设计自检

页面配置必须真正贯通到 Python 模型调用，不能只保存表单。已经覆盖账号隔离、加密持久化、任务级凭证、重启/删除行为、默认选择及环境变量兼容；首期不加入任意第三方端点或自动获取模型权限的复杂功能。

## 2026-10-20 个人设置入口补充

按用户进一步要求，将模型配置纳入 `/settings` 个人设置。侧栏与用户头像均可进入，保留 `/model-settings` 兼容地址；显示当前账号用户名、邮箱和已保存的默认模型。增加顶部默认提供商选择与明确的保存动作，区分个人密钥和服务端环境配置。只影响新任务，历史任务的配置与报告保持原样。缺少环境凭证时引导用户在个人设置保存并启用模型，不将“保存密钥”等同于“已启用默认模型”。
