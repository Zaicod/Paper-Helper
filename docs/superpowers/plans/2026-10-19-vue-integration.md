# Vue 前端接入实施计划

按已批准整体方案的 Vue 阶段实施，用户本轮明确要求接入 Vue。使用 writing-plans、test-driven-development；独立页面与接口测试可并行委派，依赖安装、构建和真实联调串行执行。没有 Git 仓库，不创建提交。

## 目标与设计

新增 `frontend-vue/`：Vue 3 + TypeScript + Vue Router + Pinia + Vite。浏览器只请求 Java `/api`，开发与预览服务器通过代理连接 Java，沿用 Cookie 会话和 CSRF，不开放后端跨域。原 React/Python 页面保留独立入口。

中文论文研究工作台采用冷白纸张 `#f4f7fb`、墨蓝文字 `#182b45`、研究蓝 `#245bea`、青绿状态 `#087f73`、细线 `#dae3ef`。固定侧栏、清晰列表和阅读区；系统中文无衬线正文、Georgia 用于少量品牌英文、等宽字体用于任务标识。研究报告的证据与阶段时间线作为特色，不使用虚构数据或虚假百分比。移动端导航改为顶栏，可键盘操作，尊重 reduced-motion。

页面：登录/注册、收藏夹列表与详情（论文录入、收藏夹笔记、论文笔记）、研究任务列表与新建、任务详情及报告。空状态提供真实操作；演示与真实模式明确区分。报告以 Vue 插值渲染，不使用未经处理的 HTML。

## 契约与交互

- `src/api/http.ts` 解包 Result；所有写请求先取 CSRF，注册/登录后更新 token；403 仅更新安全令牌并提示用户重试，不自动重放有副作用请求。401 清理用户并跳转登录。
- `src/api/index.ts` 与 `src/types.ts` 描述现有 Java 接口，不新增后端接口，不在浏览器接触内部服务密钥或模型 Key。
- `src/stores/auth.ts` 保存内存身份，刷新从 `/auth/me` 恢复；不把密码或 Cookie 写入 localStorage。路由守卫检查身份。
- 收藏夹操作有保存/删除状态与错误，删除需明确确认。列表支持分页，论文 URL 仅允许 http/https；不把人工录入标成已验证来源。
- 研究创建每次新意图生成 idempotency_key，网络错误后重试保持原键；修改输入后使用新键。选择收藏夹时只提交 Java 数字论文 ID。未选收藏夹按主题搜索。
- 运行中任务定时轮询，离开页面停止、无重叠请求；终态停止轮询；暂时失联展示同步错误和重试入口。展示分析结果、综合、构思、证据审计和部分失败，不把演示结果当真实模型结果。
