# 按账号配置模型：使用与学习

登录 Vue 工作台后，从侧栏“个人设置”或用户头像进入 `/settings`。页面显示当前账号、当前使用的大模型，以及该账号的 Qwen / OpenAI 配置。原 `/model-settings` 地址仍可使用。

先在提供商卡片中填写 API Key 和账号可用的模型名称并保存，再到顶部“默认大模型”选择提供商并点击“保存默认选择”。模型名称可手工填写，页面预设不代表账号一定有权限。仅保存密钥但仍选用“服务端配置（环境变量）”时，任务继续读取服务端环境变量；个人默认模型只影响新提交的任务，原来失败的报告可点击“重试任务”，使用当前设置创建新的执行记录。

保存后输入框会清空，刷新只显示“已配置”和密钥末尾提示。以后只改模型名称时，密钥留空会保留已有密钥；清除凭证要点击单独的“删除密钥”并确认。完整密钥不会从服务器回传，也不会写入浏览器 localStorage 或 sessionStorage。

“测试连接”使用已经保存的密钥与模型做一次很小的真实调用，可能消耗少量额度。请先保存再测试。测试成功只说明当前账号、模型和网络能完成该请求，不保证后续复杂报告的质量或可用性。失败信息会脱敏，连接调用有超时和输出限制。

新建学习报告或真实研究时，页面载入个人默认提供商与模型；在“研究设置”中可以覆盖本次模型。学习报告仍需选择收藏论文和可获取的 PDF 正文，导出已完成的 DOCX 不会再次调用模型。离线演示不需要密钥。

## 保存位置与备份

Java 将每个账号的模型设置保存在业务数据库中，API Key 使用 AES-GCM 加密。首次保存会自动在 Java 工作目录下创建 `data/model-settings-master.key`，后续启动复用同一文件。默认 `run-local.cmd` 的工作目录为 `java-backend`，因此通常是 `java-backend/data/model-settings-master.key`；通过其他目录启动时以该进程工作目录为准。

需要修改路径时使用 Java 配置 `paperflow.model-settings.key-file`，例如启动参数 `--paperflow.model-settings.key-file=D:/private/paperflow/master.key`。这个主密钥是服务器解密数据库凭证所需的本地文件，不需要把它填入网页或发到聊天。

如果备份、迁移或恢复个人模型设置，需要同时保留业务数据库和这个主密钥文件。只复制数据库无法解密原有凭证。不要提交主密钥到版本管理，也不要删除已有密文对应的主密钥；文件丢失或不匹配时，应先恢复正确的原文件，系统不会静默生成新主密钥来替代已有设置。默认主密钥文件名已加入忽略规则，即使从项目根目录启动也不会被跟踪。

## 任务如何拿到正确密钥

浏览器只向 Java 保存设置。创建任务时，Java 在普通任务记录中保存提供商、模型和凭证来源，不保存明文 Key。真正向 Python 派发时，Java 根据任务所属账号读取当前密钥，经内部服务认证传给 Python。

Python 的 `RuntimeCredentials` 使用 `SecretStr`，只在当前任务内存中存活，不写入 SQLite 的任务输入、任务哈希或公共报告，不修改进程环境或全局 SDK Key。同一任务的重复派发不会替换已经执行中的凭证；执行完成、失败和关闭时清理。

删除密钥后，已经派发的任务可继续使用派发时的凭证；还未派发且依赖该个人配置的任务会明确失败。删除默认提供商的 Key 会保留“使用个人配置”的选择，防止任务悄悄使用服务端 Key。需要切回兼容模式时，在模型设置中主动选择服务端配置。

未选择个人默认配置时，保留 Python 执行端的 `DASHSCOPE_API_KEY` / `QWEN_MODEL`、`OPENAI_API_KEY` / `OPENAI_MODEL` 兼容路径。命令行和旧 Python 网页入口的配置方式保持各自原有行为；旧 Python 网页使用的 `outputs/web/.model-settings.key` 与新的 Java 主密钥文件相互独立。

## 对照代码学习

从 Vue 的 `ModelSettingsView.vue` 看表单和独立操作，再沿 Java 的 `ModelSettingsController` → `ModelSettingsService` / `ModelSettingsServiceImpl` → MyBatis Mapper 看归属校验、脱敏和加密存储；最后看 `ResearchTaskServiceImpl` / `ResearchSynchronizer` 的派发与 Python `model_runtime.py`、`worker.py` 的任务局部凭证。

浏览器集成验证入口为 `scripts/model_settings_smoke.py`。它启动独立端口、临时 H2 / SQLite、临时主密钥和自己的服务进程，使用明确标注的假 Key 与受控模型边界，覆盖保存、刷新、保留 Key、连接测试、默认模型、Java → Python 学习报告、DOCX、删除及账号隔离。测试不读取用户真实模型凭证，不验证真实模型质量或外部厂商服务可用性。常规执行端不会导入测试替身。

## 重试失败的报告

配置好当前账号的默认模型后，回到原来失败或中断的任务，点击“重试任务”。系统沿用原任务的主题、论文快照、学习目标与笔记，按当前模型设置创建一条新的执行记录；旧任务及其报错保留。重复点击同一次重试不会反复创建新任务。

原任务中已移出个人收藏的论文不能直接重试，需要重新选择。如果需要采用修改后的论文链接或内容，也请新建任务选择更新后的资料。重试仍会实际调用模型；运行中和已完成的任务没有重试按钮。
