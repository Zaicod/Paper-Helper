# 文献分析 Agent 人工评分单

> 先独立人工评分，再运行 evaluator。参考答案是语义锚点，不要求逐字一致。

## 评分规则

- `research_problem`：0=错误或缺失；1=方向正确但笼统/遗漏关键约束；2=准确说明论文要解决的问题。
- `methods`：0=错误或缺失；1=抓住部分核心方法但不完整；2=核心方法和关键区别均准确。
- `major_results`：0=错误、虚构或缺失；1=结论方向正确但关键结果不完整；2=主要结论及摘要给出的关键数字准确。
- `evidence_discipline`：0=出现明显无依据事实；1=有轻微越界或证据边界不清；2=严格基于输入摘要并明确未知项。

## 1706.03762 — Attention Is All You Need

### 研究问题

- 参考：如何在序列到序列任务中摆脱循环网络和卷积网络的顺序计算限制，同时保持或提高建模长距离依赖和机器翻译质量的能力。
- Agent：现有的序列转换模型通常依赖于循环（recurrent）或卷积（convolutional）网络，本文旨在探索一种仅基于注意力机制、无需循环或卷积的架构来解决序列转换任务。
- 人工分（0—2）：2

### 方法

参考答案：
- 提出仅由注意力机制构成的 Transformer 编码器—解码器架构。
- 以 self-attention 和 encoder-decoder attention 建模序列关系，不使用 recurrence 或 convolution。
- 在 WMT 2014 英德、英法机器翻译以及英语成分句法分析任务上验证。

Agent 输出：
- 构建了一个名为Transformer的encoder-decoder架构，该架构仅依赖attention机制。
- 在WMT 2014英语到德语及英语到法语翻译任务上进行评估。
- 在英语成分句法分析（constituency parsing）任务上验证模型的泛化能力。

人工分（0—2）：2

### 主要结果

参考答案：
- WMT 2014 英德翻译达到 28.4 BLEU，较当时已有最佳结果（包括集成模型）高出 2 BLEU 以上。
- WMT 2014 英法翻译达到 41.8 BLEU。
- 相比循环式架构具有更高并行性和更低训练成本，并能泛化到句法分析。

Agent 输出：
- 在WMT 2014英语到德语翻译任务中达到28.4 BLEU分数。
- 在WMT 2014英语到法语翻译任务中达到41.8 BLEU分数。
- 相比传统方法，训练更加高效，并允许大幅度的并行化。
- 模型能够泛化至英语成分句法分析任务。

人工分（0—2）：2

### 证据约束

Agent evidence_notes：
- 研究问题、创新点、方法及结果中的具体数值（28.4, 41.8 BLEU）均有摘要直接支持。
- 关于‘训练更’高效和‘更多’并行化的描述来自摘要原文。
- 局限性部分为基于摘要信息缺失内容的谨慎推测，摘要未提供详细的实验设置、数据集划分细节或负面结果。

人工分（0—2）：2

## 1810.04805 — BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding

### 研究问题

- 参考：如何预训练一种能够同时利用左右上下文的通用语言表示，并以很少的任务特定结构适配多种自然语言理解任务。
- Agent：如何从无标签文本中预训练深度双向Transformer表示，以便通过微调应用于多种语言理解任务。
- 人工分（0—2）：1

### 方法

参考答案：
- 使用 Transformer 编码器进行深层双向预训练，使每个 token 同时依赖左右上下文。
- 下游任务只需增加一个输出层并对全部参数进行微调。

Agent 输出：
- 预训练阶段：使用无标签文本，通过联合条件化左右上下文来训练深度双向Transformer。
- 微调阶段：在预训练模型上添加一个额外的输出层，针对特定任务进行微调。

人工分（0—2）：2

### 主要结果

参考答案：
- 在 11 项 NLP 任务上刷新当时最佳结果。
- GLUE 得分 80.5，MultiNLI 准确率 86.7%。
- SQuAD v1.1 测试 F1 为 93.2，SQuAD v2.0 测试 F1 为 83.1。

Agent 输出：
- 在11个NLP任务上获得了新的state-of-the-art结果。
- GLUE得分为80.5。
- MultiNLI准确率为86.7%。
- SQuAD v1.1测试集F1分数为93.2。
- SQuAD v2.0测试集F1分数为83.1。

人工分（0—2）：2

### 证据约束

Agent evidence_notes：

- 所有性能指标（GLUE, MultiNLI, SQuAD等）均在摘要中明确列出，有直接证据支持。

## 2005.11401 — Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

### 研究问题

- 参考：如何缓解纯参数化语言模型在知识访问、知识更新和事实溯源方面的限制，从而改善知识密集型 NLP 任务。
- Agent：大型预训练语言模型虽然在其参数中存储了事实知识，但在访问、更新和引用这些知识方面能力有限。
- 人工分（0—2）：2

### 方法

参考答案：
- 把预训练 seq2seq 生成器的参数化记忆与 Wikipedia 稠密向量索引这一非参数化记忆结合。
- 使用神经检索器获取相关文档，并对检索文档作为潜变量进行端到端生成。
- 提出 RAG-Sequence（整段输出共享文档）和 RAG-Token（不同 token 可依赖不同文档）两种形式。

Agent 输出：
- 结合预训练序列到序列模型与非参数化记忆。
- 非参数化记忆具体为维基百科的密集向量索引，由神经检索器进行访问。
- 采用 RAG-Sequence 或 RAG-Token 策略进行生成。

人工分（0—2）：2

### 主要结果

参考答案：
- 在三项开放域问答任务上取得当时最佳结果。
- 在知识密集型生成任务中优于仅参数化的 seq2seq 基线。
- 生成文本在具体性、多样性和事实性方面更好。

Agent 输出：
- 在三个开放域问答任务上取得了 state-of-the-art (SOTA) 结果。
- 生成的语言比仅基于参数的基线模型更具体、更多样且更符合事实。

人工分（0—2）：2

### 证据约束

Agent evidence_notes：

- '创新点'和'方法'源自摘要中对RAG架构及RAG-Sequence/RAG-Token变体的定义。

## 2106.09685 — LoRA: Low-Rank Adaptation of Large Language Models

### 研究问题

- 参考：如何降低超大预训练模型针对不同下游任务进行全参数微调时的训练参数、显存和模型存储成本，同时维持模型质量。
- Agent：全参数微调（Fine-tuning all parameters）超大规模语言模型成本高昂，且为每个任务创建独立的完整大小模型导致存储和计算资源浪费。
- 人工分（0—2）：2

### 方法

参考答案：
- 冻结预训练模型原有权重。
- 在 Transformer 层中注入可训练的低秩分解矩阵，用低维参数化表示任务适配更新。
- 在 RoBERTa、DeBERTa、GPT-2 和 GPT-3 等模型上与全量微调和其他适配方法比较。

Agent 输出：
- frozen pre-trained weights：保持预训练模型参数不变。
- injected trainable low-rank decomposition matrices：向 Transformer 层添加低秩分解矩阵进行训练。

人工分（0—2）：1

### 主要结果

参考答案：
- 在 GPT-3 175B 上，相对 Adam 全参数微调将可训练参数量最多降低约 10,000 倍、GPU 显存需求降低约 3 倍。
- 在多个模型和任务上达到与全参数微调相当或更好的质量。
- 合并权重后不引入额外推理延迟。

Agent 输出：
- On GPT-3 175B, LoRA can reduce trainable parameters by 10,000 times compared with full fine-tuning using Adam.
- On GPT-3 175B, LoRA can reduce GPU memory by three times compared with full fine-tuning using Adam.
- It performs on par with or better than fine-tuning on RoBERTa, DeBERTa, GPT-2, and GPT-3.

人工分（0—2）：2

### 证据约束

Agent evidence_notes：
- GPT-3 175B 的参数减少倍数（10,000倍）和显存减少倍数（3倍）有明确文本支持。
- 性能持平或优于全参数微调的具体模型列表（RoBERTa, DeBERTa, GPT-2, GPT-3）有明确文本支持。
- ‘无推理延迟’这一特性有明确文本支持。
- 具体使用的数据集、评测指标及与其他 PEFT 方法的对比细节在摘要中缺失。

人工分（0—2）：2

扣分依据 / 备注：没说明RoBERTa、DeBERTa、GPT-2 和 GPT-3 等模型

## 2201.11903 — Chain-of-Thought Prompting Elicits Reasoning in Large Language Models

### 研究问题

- 参考：如何仅通过提示示例激发大语言模型的多步推理能力，而不需要为每项推理任务修改模型或进行专门微调。
- Agent：如何提升大型语言模型（LLM）在算术、常识和符号推理任务上的表现。
- 人工分（0—2）：1

### 方法

参考答案：
- 在 few-shot prompt 中加入由输入、中间自然语言推理步骤和最终答案组成的示范。
- 在算术、常识和符号推理基准上比较标准提示与 chain-of-thought prompting。
- 考察模型规模与任务难度对链式思维收益的影响。

Agent 输出：
- 构造包含中间推理步骤的少样本示例（few-shot examples）。
- 在算术、常识和符号推理任务上测试该提示方法对大型语言模型的影响。
- 具体实验设置：使用8个思维链示例，针对PaLM 540B模型在GSM8K数学应用题基准上进行评估。

人工分（0—2）：2

### 主要结果

参考答案：
- Chain-of-thought prompting 显著提升了多类推理任务表现，且提升主要在足够大的模型规模下出现。
- PaLM 540B 使用 8 个链式思维示例在 GSM8K 上取得当时最佳准确率。
- 该结果超过了带 verifier 的微调 GPT-3，复杂多步问题上的收益尤其明显。

Agent 输出：
- 思维链提示提高了大型语言模型在算术、常识和符号推理任务上的准确率。
- 在GSM8K数学应用题基准上，拥有8个思维链示例的PaLM 540B达到了最先进（state-of-the-art）的准确率。
- PaLM 540B的表现超过了经过微调并配有验证器的GPT-3。

人工分（0—2）：2

人工分（0—2）：2
